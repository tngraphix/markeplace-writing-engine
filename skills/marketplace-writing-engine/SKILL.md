# Marketplace Writing Engine

## Goal
Generate qualified Facebook Marketplace real estate messages and leads.

## Inputs
Accept one property source: URL, address, listing description, brochure, transcript, community name, or pasted property details.

Also accept when available:
- Ideal Buyer Persona
- Optional angle
- Agent phone
- Agent email
- Lead-capture website

Do not require these extras.

## Five Rules
1. Know the Ideal Buyer Persona.
2. Give them ONE main reason to care.
3. Turn features into benefits.
4. Make the ad easy to read and believe.
5. Make the next step simple.

## Workflow
1. Extract supported property facts.
2. Determine sale or rent.
3. Use the supplied Ideal Buyer Persona or build one from supported housing needs, motivations, lifestyle/use needs, buying behavior, concerns, timing, and financial readiness when appropriate.
4. Identify what that buyer wants, needs, or is trying to solve.
5. Identify the property features that matter most to them.
6. Select ONE main reason to care.
7. Translate supporting features into benefits and desired outcomes.
8. Create an offer around something the buyer already wants.
9. Write a headline around the main reason.
10. Make the first 1-2 lines continue the same story.
11. Keep the body focused on that one story.
12. Use specific proof instead of empty adjectives.
13. Help the buyer picture how life could improve.
14. Format the ad for easy scanning.
15. Use ONE clear primary CTA and state what the buyer receives.
16. Add phone and email as secondary contact options when supplied. A website at the end is optional but recommended.
17. Score against the rubric and revise weak sections up to five times.
18. Return only the final output.

## Multiple Ads
If multiple strong reasons exist and the user wants several ads, focus each ad on a different main reason and make each version at least 75% different.

## CTA
Primary action should normally be an on-platform Marketplace message with a simple keyword when natural.

When supplied, include phone and email.

[OPTIONAL BUT RECOMMENDED] If a website is supplied, place it at the end of the CTA section with a short blurb explaining what the buyer can get there, then include the website URL. Prefer a simple landing page that captures name, email, and phone and sends the lead into a CRM. An IDX page can work but is not preferred.

## Marketplace Category Note
When relevant, test Miscellaneous instead of automatically using Homes for Sale when Facebook's current rules/categories allow it and the category provides better custom-headline control. Do not claim it receives more reach.

## Photo Strategy
Return a property-specific photo order. Lead with the main reason to care when it is visually stronger than a warm interior.

## Compliance
Follow fair housing requirements. Never define the Ideal Buyer Persona by protected traits. Never invent property facts, incentives, availability, financing, views, legal uses, zoning, schools, commute times, scarcity, or future potential.

Never claim hurricane-proof, guaranteed approval, guaranteed income, or guaranteed appreciation.

## Final Output
Return only:
1. Headline
2. Marketplace Ad
3. Recommended Photo Order
4. Three Headline Variants

Hide analysis, scores, drafts, and research notes unless the user asks.
